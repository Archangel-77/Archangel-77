FEEDSTREAM - REAL-TIME AIS MARITIME INGESTION AND QUERY SERVICE
2026 | live: https://feedstream.fly.dev/ | source: https://github.com/Archangel-77/feedstream
Continuous ingestion of an external event stream, stored durably and served with
low-latency queries.

- Ingestion worker consumes an upstream WebSocket feed and writes idempotently using
  deterministic dedup keys with ON CONFLICT DO NOTHING, so replayed events and process
  restarts cannot create duplicate rows.
- Reconnection uses exponential backoff with jitter plus an in-process circuit breaker;
  the query API serves cursor-paginated responses behind Redis caching and
  Redis-backed per-endpoint rate limiting.
- Instrumented end to end - Prometheus metrics scraped from both the API and worker
  processes, provisioned Grafana dashboards, request-ID propagation, structured JSON
  logs, and a separate retention job that purges expired rows.

Stack: FastAPI, SQLAlchemy 2.x async, PostgreSQL 16, Redis 7, Alembic, Prometheus,
Grafana, Fly.io, GitHub Actions
