Conductor — PostgreSQL-backed async task queue
2026 · open source · PyPI

Async task queue for Python that uses PostgreSQL instead of Redis or a message broker.

  • Workers claim a task and mark it processing in the same statement with FOR UPDATE SKIP LOCKED, so two workers cannot take the same row.
  • Retries default to exponential backoff and exhausted tasks go to a dead-letter queue; recurring tasks, priority routes and per-task-type circuit breakers are included.
  • About 11,600 lines of Python with roughly as much test code, plus Prometheus metrics, a React dashboard, and gRPC and HTTP APIs.

Stack  Python 3.11+ · asyncio · PostgreSQL · asyncpg · Pydantic · gRPC · Prometheus · FastAPI + React

feedstream — AIS maritime ingestion and query service
2026 · source

Ingests live AIS ship positions over a WebSocket and serves them through FastAPI.

  • Writes are deduplicated with ON CONFLICT DO NOTHING on an MMSI / message-type / timestamp key, so a replayed event or a process restart inserts nothing.
  • The upstream connection retries with random exponential backoff behind a circuit breaker; Redis caches query results and rate limiting is applied per endpoint.
  • Prometheus metrics from the API and the worker, provisioned Grafana dashboards, request-ID propagation, and a retention job that purges expired rows. Runs on Docker Compose with Postgres, Redis, Prometheus and Grafana.

Stack  FastAPI · SQLAlchemy 2.x async · PostgreSQL 16 · Redis 7 · Alembic · Prometheus · Grafana · Docker
