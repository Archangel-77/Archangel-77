Conductor — PostgreSQL-backed async task queue
2026 · open source · PyPI v0.2.0

Reliable background jobs for Python teams that do not want to operate a message broker.

  • Implemented atomic claiming with FOR UPDATE SKIP LOCKED so a task is never handed to two workers concurrently; delivery is at-least-once, with idempotent handlers named as the contract in the docs.
  • Built retries with exponential backoff, a dead-letter queue with retry and discard, priority routing, recurring cron schedules, per-task-type circuit breakers, and dependency chains that propagate BLOCKED state.
  • Instrumented with Prometheus metrics, health endpoints, and structured logging; added a React dashboard, a gRPC API for polyglot workers, and deployment artifacts for Docker, Kubernetes, and systemd.

feedstream — real-time AIS maritime ingestion and query service
2026 · live · source

Continuous ingestion of an external event stream, stored durably and served with low-latency queries.

  • Ingestion worker consumes an upstream WebSocket feed and writes idempotently using deterministic dedup keys with ON CONFLICT DO NOTHING, so replayed events and process restarts cannot create duplicate rows.
  • Reconnection uses exponential backoff with jitter plus an in-process circuit breaker; the query API serves cursor-paginated responses behind Redis caching and Redis-backed per-endpoint rate limiting.
  • Instrumented end to end — Prometheus metrics scraped from both the API and worker processes, provisioned Grafana dashboards, request-ID propagation, structured JSON logs, and a separate retention job that purges expired rows.
